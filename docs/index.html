GLARI: Gut-Liver Axis Risk & Intervention model

An open, reproducible five-state ODE model linking gut barrier failure, portal endotoxin load, liver sinusoidal endothelial (LSEC) fenestration, microbiome resilience and dysbiosis, with ClinVar genotype risk and a combined day-15 therapy.

Work in progress. D_max and k_kupffer are placeholder values chosen to keep the system bounded, not fitted to data. A healthy untreated patient still declines, so the model is not yet calibrated, and it does not reproduce the figures in the AASLD abstract draft.

Not for clinical use.

How it works

  • Gut influx into the portal vein rises steeply (sigmoid) as integrity p falls below pc, and scales with gastric cancer stage, genotype risk and EBV status.
  • Load is cleared by the LSEC sieve (∝ fenestral area), the microbial network, and Kupffer cells.
  • High load shrinks fenestrae, erodes integrity and resilience, and drives logistic dysbiosis growth.
  • From day 15 the treated arm adds butyrate/SCFA barrier repair, an sGC stimulator, a synbiotic and pathobiont suppression.
  • Integration uses SciPy's implicit Radau solver, split at the therapy switch; solver failures stop the run with an error.

Run it locally

git clone https://github.com/SivaKoganti/Human-Gut.git
cd Human-Gut
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -e ".[dev]"
glari --seed 42                  # or: python -m glari --variants --no-ebv
pytest
