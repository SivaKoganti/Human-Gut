# Security Policy

This is a research simulation: it reads no files, opens no network connections, and handles no patient data. Variant inputs are validated against the built-in ClinVar table.

If you find a security issue (for example in the CI workflows or dependency ranges), please report it privately through GitHub's **Security → Report a vulnerability** on this repository rather than opening a public issue.

**Not for clinical use.** Model outputs are illustrative and must not inform diagnosis or treatment.
